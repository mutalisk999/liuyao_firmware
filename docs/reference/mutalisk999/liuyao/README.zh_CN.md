# 六爻（Liu Yao）

面向 AI Passport 的传统文王纳甲六爻算卦固件。心中默念所问之事，在设备上摇卦六次，即可得到完整卦盘与解读——全程离线。

## 功能

- **开机直达应用**：封面为太极图案与"六爻"大字；固件内没有测试菜单，也不使用任何网络。
- **逐步引导，一屏一事**：问事分类 →（感情视角）→ 起卦日期时间 → 起卦方式 → 六次摇卦 → 卦盘 → 四页解读。
- **九类问事**（综合、事业、求财、感情、学业、出行、家宅、官司、家庭）自动取用神：事业/官司取官鬼，求财取妻财，学业/家宅取父母，出行取世爻；感情可按"男问妻财、女问官鬼"的传统口径取用。
- **两种起卦方式**：设备摇卦——三枚模拟铜钱带短动画，按一次出一爻，6..9 的取值来自硬件随机数，分布与传统 1/8-3/8-3/8-1/8 一致；或手动录入线下摇好的铜钱结果。
- **真实干支历法**：日柱（含 23 时晚子时归次日）、月柱按分钟级节气分界（节气表由 lunar_python 1.4.8 生成，覆盖 2020-2040）、年柱以立春为界。上次输入的日期存入 NVS 记忆；首次开机默认编译日期。
- **完整纳甲卦盘**：本卦/变卦卦名、八宫与卦世、世应爻、逐爻纳甲干支、六亲、六兽、旬空、月破、日冲、伏神与飞神、动爻变化（含化进/化退/化空标记）、六冲六合及其互变。
- **四页解读**：卦象总览；用神在月建日辰下的旺衰；动爻对世爻与用神的作用及应期候选（填实、冲空、逢值逢合）；相对倾向结论（趋吉/中平/偏滞）与文化参考声明。全部文本由设备端确定性规则事实生成——无云端、无 AI 服务。
- **中文字库**：基于 Noto Sans SC（OFL 许可）生成的 16/24/48px 应用子集；字符清单直接从源码提取，显示的每个字都有覆盖契约（见 `assets/README.md`）。

## 交互

三键，竖屏：

- **上/下（短按）**：移动选中项；调整日期字段；解读页滚动；手动录爻换爻值。
- **确定（短按）**：确认；摇卦页摇一爻；解读翻页（末页再按回封面）。
- **确定（长按）**：返回上一级（结果页直接回封面）。

## 验证

- 主机测试：1424 个历法样本（常规日期 + 每个节气分界 ±1 天）、330 个排盘黄金向量（由 fortune-liuyao skill 的确定性引擎生成）；全部黄金向量的解读生成均验证不截断，并抽样校验关键内容。
- 引擎一致性：C 实现必须与 Python 参考引擎的指纹完全一致；历法与引擎测试都接入了 `tools/validate.sh --static`。
- 设备上的实际渲染、按键手感与动画节奏仍属设备测试项。
