# Liu Yao (Six Lines Divination)

A traditional Wenwang Najia Liu Yao divination firmware for the AI Passport.
Hold a question in mind, cast three coins six times on the device, and read a
full chart with an interpretation — fully offline.

## What it does

- **Boots straight into the app**: a cover screen with a taiji emblem and the
  big "Liu Yao" title; no test menu and no network use anywhere in the firmware.
- **Guided flow, one decision per screen**: question category → (relationship
  perspective) → cast date/time → cast method → six cast lines → chart →
  four-page reading.
- **Nine question categories** (general, career, wealth, relationship,
  academic, travel, home, legal, family) select the classic "useful god" (yongshen):
  Gui for career/legal, Cai for wealth, Fu for academic/home, the Self line (shi)
  for travel; relationships optionally follow the male/female perspective
  convention.
- **Two casting modes**: shake on the device — three simulated coins with a
  short animation, one line per press, values 6..9 drawn from the hardware
  RNG with the traditional 1/8-3/8-3/8-1/8 distribution — or manual entry of
  coins already shaken offline.
- **True Ganzhi calendar**: day pillar (with the late-zi-hour roll to the next
  day), month pillar from solar-term boundaries accurate to the minute
  (table generated from lunar_python 1.4.8, valid 2020–2040), year pillar from
  Lichun. The last entered date is remembered in NVS; the first-boot default
  is the build date.
- **Full Najia chart**: original and changed hexagram names, palace and stage,
  Self/Other (shi/ying) lines, najia stems-branches with six relatives and six spirits per
  line, void branches, month break, day clash, hidden lines with flying gods,
  moving-line changes with advance/retreat and void-change marks, six-clash /
  six-harmony patterns and their transitions.
- **Four-page reading**: hexagram overview; useful-god strength under the
  month/day; moving lines with their effect on the Self line and the useful god
  plus timing candidates (fill-void, clash-void, value/harmony days); and a
  relative conclusion (favorable / mixed / sluggish) with the cultural-
  reference disclaimer. All text is generated on-device from deterministic
  rule facts — no cloud, no AI service.
- **Chinese fonts**: application subsets generated from Noto Sans SC (OFL) at
  16/24/48 px; the glyph inventory is extracted from the sources, so every
  displayed string is covered by contract (see `assets/README.md`).

## Interaction

Three keys, portrait orientation:

- **UP / DOWN (click)**: move the selection; adjust date fields; scroll the
  reading page; cycle the manual-entry line value.
- **OK (click)**: confirm; shake one line on the casting screen; advance to
  the next reading page (after the last page, return to the cover).
- **OK (hold)**: go back one level (or to the cover from results).

## Verification

- Host tests: 1424 calendar samples (regular dates plus every solar-term
  boundary ±1 day) and 330 engine golden vectors generated by the
  fortune-liuyao skill's standalone engine; reading generation exercised for
  every golden cast (no truncation) plus content spot checks.
- Engine parity: the C implementation must reproduce the Python reference
  fingerprint exactly; both calendar and engine suites are wired into
  `tools/validate.sh --static`.
- On-device rendering, button feel, and animation timing remain device checks.
